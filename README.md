Présentation du projet
Élan Fitness est un projet de développement web visant à transformer un site web One Page en un site multipage pour améliorer la présence en ligne d'une salle de sport

*Objectifs*
Créer un site web multipage
Présenter les programmes et les services de la salle de sport
Améliorer l'expérience utilisateur
Adapter le site aux ordinateurs, tablettes et téléphones
Appliquer les bonnes pratiques HTML et CSS

*Technologies utilisées*
HTML5 : structure et contenu des pages.
CSS3 : mise en page, design et responsive design.

*Fonctionnalités*
Accueil : présentation de la salle de sport.
À propos : informations sur la salle et son équipe.
Programmes : présentation des activités sportives.
Navigation : liens entre les différentes pages.
Responsive design : adaptation aux différentes tailles d'écran.
Design moderne : utilisation de couleurs, de typographies et d'images cohérentes avec l'identité visuelle de la marque.

*Compétences développées*

Ce projet permet de pratiquer et de renforcer les connaissances suivantes :

Structure HTML et balises sémantiques.
Sélecteurs et propriétés CSS.
Gestion des marges et des espacements (margin, padding).
Mise en page avec Flexbox et Grid.
Gestion des images et des typographies.
Responsive design avec les media queries.
Navigation entre plusieurs pages HTML.
Organisation des fichiers d'un projet web.
Utilisation de Git et GitHub.
